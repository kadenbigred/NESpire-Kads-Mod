NESpire v0.30 - Kad's Mod

---

### **[ About ]**

NESpire is an emulator that allows you to play Nintendo Entertainment
System (NES) games on the TI-Nspire family of calculators.

No AI was used in the creation of this fork, but I am not very well versed in assembly so the code may be messy.

---

### **[ Using NESpire ]**

First, you must have Ndless installed to use NESpire. Ndless can be found
at https://ndless.me/

Any NES ROM you wish to play must be named with a .nes.tns extension, and
sent to the calculator in the same folder NESpire was sent to. Open NESpire
from the documents menu, and you will be presented with the ROM selection
menu. Choose a ROM using the arrow keys and press Shift to select one,
or press Esc to exit.

### **[ Controls ]**
######  Note: I do not own a clickpad model for testing, so functionality may be limited or nonfunctional. If you would like to test the functionality, feel free to do so and let me know.


|NES Input | Touchpad|Clickpad
|--|--|--|
|B| Menu |Esc|
|A| Doc |Tab|
|Select| Del |Clear|
|Start| Var |Shift|
|Up| 8 |Up|
|Down| 5 |Down|
|Left| 4 |Left|
|Right| 6 |Right|

######  The controls below are the same across both Touchpad and Clickpad
|Emulator Function | Button|
|--|--|
|Save State|1|
|Load State|3|
|Fast-forward|×|
|Invert Border Color|B|
|P|Pause|
|Quit|Q|
|Invert Game Colors|R|


######  Pausing via the P key instead of the ingame pause menu will save battery life

### **[ Known Issues ]**

* Saved games (e.g. in Zelda, Final Fantasy) are not yet implemented, but are planned.
* Marble Madness: Display of text window at beginning of level is glitchy.
* Super Mario Bros. 3: Ground in title screen shakes up a down by 1 pixel.
